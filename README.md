## 시그널 크래프트 백엔드 서버

### 프로젝트 소개
디바이스의 신호를 MQTT 프로토콜을 사용하여 수집하고, 이를 분석하여 사용자 및 인하우스에 정보를 제공하는 백엔드 서버입니다.

### 주요 기능
- MQTT 브로커와의 통신을 통해 디바이스에서 전송되는 신호 데이터를 수집합니다.
- 스토리지에 업로드 가능한 Presigned URL을 생성하여 디바이스가 데이터를 업로드할 수 있도록 지원합니다.
- 오디오 데이터 업로드 정보를 DB에 저장해서 ML 서버가 분석할 수 있도록 합니다.

### 기술 스택
- **언어**: Python
- **프레임워크**: FastAPI
- **MQTT 라이브러리**: paho-mqtt
- **데이터베이스**: 
   1. Document DB: Firestore(신호 데이터 저장)
   2. RDB : PostgreSQL(유저 / 디바이스 정보 저장)
- **스토리지**: GCP Storage(오디오 데이터 저장)
- **인프라**: GCP
